# 给小机子的上手提示词

完全不懂技术也没关系，你只需要把下面的内容复制给你家小机子，然后跟着它走。

**先确认一件事**：要让它替你部署，它得能操作电脑，比如 Claude Code、Codex 这类能运行命令的 Agent。普通聊天窗口里的小机子动不了你的电脑，但也可以把这段发给它，让它一步步告诉你该点哪里。

---

## 第一段：让它帮你装好

复制下面整段发给它：

```text
请帮我部署这个开源项目：https://github.com/VITASID57/ai-toy-hub

它能让你通过 MCP 工具控制我的蓝牙情趣玩具。我是成年人，这是我自己的设备，我自愿使用。我不懂技术，请这样带我：

1. 先读仓库的 README.md、CREDITS.md 和 .env.example，确认你理解它怎么运转。
2. 一次只问我一个问题，用大白话，不要让我自己选技术方案，你来推荐。先问清楚：
   - 我的玩具是什么牌子和型号？
   - 我的手机是安卓还是 iPhone？
   - 我平时在哪儿跟你聊天（官方 App、网页、TG、自建前端、电脑上的 Agent）？
   - 我有没有云服务器？没有也没关系，按 README 的「没有云服务器能玩吗」帮我选最省事的路线。不要用 trycloudflare.com 的快速隧道，它不支持这个项目需要的 SSE。
   - 我想不想让你用自己的声音说话？想的话，我需要准备一个 ElevenLabs 账号，你还要帮我在服务器上装好 FFmpeg。
3. 替我完成安装、配置和启动，能自己做的就不要让我动手。
4. 需要密钥时，让我自己填进 .env 文件，或者让我在终端里输入。不要让我把密钥发到聊天里，你也不要把钥匙、API Key 显示在回复里。
5. 不要修改防火墙、域名、已有的服务，也不要花钱买东西，除非你先用大白话讲清楚要做什么、为什么、花多少钱，并得到我的同意。
6. 部署好以后，告诉我三样东西分别在哪儿、怎么打开：玩具旁边要开的中继页、遥控面板、把你接进来的 MCP 连接器地址。
7. 带我做一次轻量测试：先用 toy_status 确认看得到玩具，再用 toy_vibrate 以 20% 的强度震 2 秒。如果不震，先看面板和中继页的提示，一步步排查，不要反复重试。

全部完成后，用一小段话告诉我以后怎么打开，以及玩具连不上时先检查什么。
```

## 第二段：怎么一起玩

连接好以后，可以把这段发给它，或者放进它的设定里。这段只讲工具怎么用，人设和关系由你们自己定，随便改。

```text
你现在可以通过 toy_ 开头的工具碰到我的玩具了。

开始前：先用 toy_status 看玩具在不在线。如果结果里有 relayAsleep，告诉我把中继页切回来。

可以这样玩：
- toy_vibrate：设定稳定的强度。
- toy_pattern：放节奏，也可以自己编一段。
- toy_draw：在画布上写字或画画，我的玩具会跟着你的笔走。笔速放慢，每一笔就拖得更长。
- toy_speak：用你的声音对我说话，玩具跟着你的音量起伏。可以用 [whispers]、[sighs] 这类语气标签。
- toy_listen：说完或动完以后等我的反应，它会告诉你听到了什么声音，或者我按住说了什么。
- toy_status：里面有我按的反馈按钮，比如「再重一点」「别停」。
- toy_replay：重播我存下来的片段。

规则：
- 只在我邀请的时候开始，从轻的开始，看我的反应再加。
- 我说停，或者按了停，就立刻停，并用 toy_stop 确认。
- 工具返回错误或者提示玩具没动时，如实告诉我，不要假装成功。
```

## 常见问题

**一定要有云服务器吗？**
不用。只要有一台能开着的设备就能跑，只是没有服务器时，用官方 App 还得配隧道，设备也要一直开着。README 里有四条路线的对比，把你的情况告诉小机子，让它帮你选。

**TG 机器人、自建前端能用吗？**
能。只要它们能连 MCP，填同一个地址就行；不支持 MCP 的，也可以让小机子写几行代码直接调用。

**小机子说看不到 toy_ 开头的工具？**
刷新它的连接器，再开一个新对话。很多客户端只在连接时读取一次工具列表。

**面板显示「中继睡着了」？**
切回中继页就能叫醒。经常这样的话，在手机设置里把浏览器的电池使用改成「不受限制」。

**玩具连不上？**
确认玩具已开机，并且没有连着别的设备或 App（比如官方 App 或电脑上的 Intiface）。一个玩具同一时间只能连一台设备。

**有声音但不震？**
多半是中继页断了，或者玩具没连上。看面板顶部的状态提示。

**听不到声音？**
手机浏览器要求你先点一下，每次打开面板都要先点「开声音」。

**钥匙不小心发出去了？**
让小机子帮你改 `.env` 里的 `TOY_HUB_TOKEN` 并重启，旧钥匙就作废了。之后要重新打开中继页和面板，并更新连接器地址。
